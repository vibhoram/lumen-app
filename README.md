# Lumen

A Dynamic Island–style overlay for Windows 10/11 — music, focus, Clara, clipboard, weather, a pet, and more.

**Made by Vibhor Maheshwari** · Studio: [Webser](https://webser.app)

## Download

**[Lumen-Setup-1.3.1.exe](https://github.com/vibhoram/lumen-app/releases/latest/download/Lumen-Setup-1.3.1.exe)** · [All releases](https://github.com/vibhoram/lumen-app/releases)

Per-user install (no admin). Clara needs **your own** Gemini / OpenRouter / Groq API key — Lumen never ships with one.

> SmartScreen may warn once (unsigned). More info → Run anyway. Later updates install themselves from Settings → Updates.

> Lumen is **not** an official D-Island release. It uses a different name and icon.
